# peru-modelling

> **Archived.** No longer maintained; last updated June 2016.

Web page and materials for a one-day course on modelling infectious diseases held in Peru on 9 June 2016. The page, by Gwen Knight, lists the software needed and links to the lab practical and the lecture slides.

- `index.html`: the course page.
- `intro_to_r_gk.html`: the R introduction for the lab session.
- `intro_modelling_peru.pdf`: lecture slides, "An introduction to infectious disease modelling and its applications".
